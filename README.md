# TaskTracker 
Sistema de Interface de Linha de Comando (CLI) para gerenciamento de tarefas, desenvolvido como parte da Fase 2 do Bootcamp II.

## Funcionalidades
- Cadastro de tarefas com validação de dados.
- Classificação por prioridade (Alta, Média, Baixa).
- Visualização rápida da lista de pendências.

## Tecnologias Utilizadas
- Python 3
- Git & GitHub

## Como Executar
1. Clone o repositório: `git clone <link-do-seu-repositorio>`
2. Acesse a pasta: `cd tasktracker-projeto`
3. Execute a aplicação: `python src/main.py`
